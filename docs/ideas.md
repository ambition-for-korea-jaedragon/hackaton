## 선택·이유·대가 (확정: B, 사용자 결정 2026-10-24)

- **이유:** 고통 근거가 가장 강한 (d)를 팀의 아이돌 룩 아이디어에 붙인다. 소비자가 K-아이돌 룩 → K-뷰티 SKU → 내 톤 발색을 한 번에 보는 도구는 조사 범위에서 못 찾았다. 데모 끝 상태(내 얼굴 전/후)가 눈에 보인다.
- **대가:**
  - 범위(사용자 확정 2026-10-24): **기초(스킨케어 prep) → 베이스 → 아이 → 블러셔 → 립** 전 단계. 얼굴 오버레이는 아이(섀도·라이너)·블러셔·립, 베이스는 톤 매칭 쉐이드 추천, 기초는 원하는 피부 질감을 위한 스킨케어 단계·제품(시뮬레이션 없음). 정확 브랜드 식별·실시간 영상은 뺀다.
  - 늦어지면 줄일 순서: 아이라이너 디테일 → 아이섀도 그라데이션(단색으로) → 베이스 오버레이(추천만 유지). 기초·립·블러셔는 유지.
  - Claude는 정확한 제품을 맞히지 않는다. 색 계열·기법·단계를 뽑고, 20~30개 **큐레이션 샘플 카탈로그**에 매핑한다(샘플 배지).
  - 발색은 화면 근사치다. "참고용 시뮬레이션"으로 표시한다.
  - 공개 데모에 아이돌 사진을 쓰지 않는다. 샘플 룩은 팀 본인·생성 이미지, 사용자는 직접 업로드. 13+ 게이트, 얼굴은 브라우저 내 처리·미저장.
  - Gen Alpha(13세 미만)는 타깃에서 제외한다.

| ① 룩 분석 | 아이돌·원하는 메이크업 사진 → 사용 제품(색 계열·카테고리)과 방법 설명 |
