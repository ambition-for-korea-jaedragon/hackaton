# Ambition for Korea 규칙·일정

근거: [주최자 홈페이지](https://bloomworld.ai/community/ambition/), [Luma](https://luma.com/d7ypbx8t), 현장 안내. 수정 공지가 있으면 갱신한다.

## 필수 규칙

| 항목 | 규칙 |
|---|---|
| 기획·개발 | 현장에서 시작 |
| 제품 코드 | 10:00 KST 이후 새 공개 GitHub 레포에서 작성. 기존 제품 코드 사용 금지 |
| 기록 | `main`에 push. 레포·커밋으로 규칙 준수를 판단하며 현장 공개 |
| 주제 선언 | **10:30까지** 주제·한 줄 아이디어·해외 타깃·공개 레포 등록 |
| 자원 | 개발·AI는 지급 Claude 크레딧. 1인 $500, 유효기간 30일, 조직 공동 사용 가능. **외부 모델(제품 내 이미지 생성) 사용 가능 — 팀원이 운영진에 문의해 확인, 2026-10-24 오전(문구 원문 미기록)** |
| 주변 도구 | 디자인·영상 도구 사용 가능, 비용은 각자 부담 |
| 제출 | 10:00–17:00, **팀당 1회**. 8팀 통과 시 조기 종료 |
| 판정 | VC 3 PASS → 결선, 3 FAIL → 탈락. 늦어도 15시부터 본격 심사 |
| 데모 | VC가 직접 사용. **최소 21:00까지 유지** |
| 덱 | PDF 2장 이하, 16:9. 매 장 공식 로고 띠 |
| 결선 | 영어 발표 3분 + 한국어 Q&A 7분 |

평가 기준은 같은 자원으로 만든 가치. 세부 배점은 비공개. 팀 2~4인, 상금 대신 후속 VC 미팅. 남은 결선 자리는 현장 스크린에 표시된다. 개발·AI를 개인·회사 크레딧으로 이어 쓸 수 없다.

## 제출 패킷

공식 페이지: https://ambition-for-korea.vercel.app/submit

서비스 이름(60자 이내), 영어 한 줄 소개(160자 이내), 해외 타깃(100자 이내), 데모 URL, 사용법 3줄(500자 이내), PDF, 공개 레포, 오늘 만든 부분 한 줄(400자 이내). 글자 제한·필드는 제출 폼이 우선한다. 주제 선언과 최종 제출은 별개다. PDF 업로드가 안 되면 공개 PDF URL을 받는다.

공식 키트: https://ambition-for-korea.vercel.app/kit/ . 1장은 무엇을 누구에게, 2장은 오늘 만든 것. 일반 VC 덱 조언보다 키트 구성이 우선한다. 1920×1080, 본문 28px 이상, 왼쪽 위 팀 이름, 하단 로고 띠 폭 약 90%·아래 여백 약 3%. 로고 비율·색을 바꾸거나 가리지 않는다.

## 행사 시간

08:30 입장 → 08:45 착석 → 09:00 개회사 → 09:20 Anthropic 세션 → 약 09:40 주제·크레딧 → 10:00 코드 작성·제출 시작 → **10:30 선언 마감** → 17:00 제출 마감 → 19:00 결선 → 21:00 종료.


## 팀 운영 전제


권장 13:30 제출, 14:00 전 준비 완료. 15시 본격 심사 안내가 있어도 그때까지 기다리지 않는다. 운영판은 `runbook.md`, 팀별 실행 정보는 `context.md`. 접근 장벽을 줄이되, 인증이 필요한지는 주제·데이터에 따라 정한다. 공지는 테스트 계정을 함께 안내할 수 있도록 한다.
